# 上册基础讲义：有理数入门

适用对象：刚开始学习初中数学、整数和负数概念不牢固的学生。

## 1. 正数、负数和 0

- 大于 0 的数叫正数，例如 3、0.8。
- 小于 0 的数叫负数，例如 -2、-0.5。
- 0 既不是正数，也不是负数。

生活例子：海平面以上 5 米可以记作 +5 米；海平面以下 3 米可以记作 -3 米。

## 2. 数轴

数轴包含原点、正方向和单位长度。数轴上，右边的数比左边的数大。

例如：-3 < -1 < 0 < 2。

注意：负数比较大小时，离 0 更远的负数反而更小，所以 -5 < -2。

## 3. 相反数

只有符号不同、绝对值相同的两个数互为相反数。

- 3 的相反数是 -3。
- -7 的相反数是 7。
- 0 的相反数是 0。

一个数的相反数可以理解为：在数轴上关于原点对称的点所表示的数。

## 4. 绝对值

一个数的绝对值表示它到原点的距离，所以绝对值不会小于 0。

- |3| = 3
- |-3| = 3
- |0| = 0

常见错误：认为负数的绝对值仍然是负数。距离不可能是负数，因此 |-4| = 4。

## 5. 有理数分类

有理数包括整数和分数。有限小数、无限循环小数都可以表示成分数，因此也属于有理数。

本阶段先熟悉整数、分数、正数、负数及 0 的分类，不必急于记复杂定义。

## 6. 分步例题

例 1：比较 -4 和 -1 的大小。

步骤：
1. 在数轴上找到 -4 和 -1。
2. -4 在 -1 的左边。
3. 因此 -4 < -1。

例 2：求 -6 的相反数和绝对值。

步骤：
1. 相反数只改变符号，所以 -6 的相反数是 6。
2. 绝对值表示到原点的距离，所以 |-6| = 6。

## 7. 基础练习

1. 下列数中，哪些是负数：4，-3，0，-0.7？
2. 比较大小：-2 □ 1。
3. 比较大小：-6 □ -4。
4. 写出 9 的相反数。
5. 写出 -8 的相反数。
6. 计算：|−5|。
7. 计算：|0|。
8. 在数轴上，-2 和 3 哪个点在右边？
9. 某地气温为零下 4 摄氏度，用带符号的数表示。
10. 判断：0 是正数吗？

## 8. 提高练习

1. 已知一个数的绝对值是 5，这个数可能是多少？
2. 将 -3、2、-1、0 按从小到大排列。
3. 如果 a 是负数，|a| 与 a 的符号有什么不同？

## 9. 答案与解析

基础题：
1. -3、-0.7。它们都小于 0。
2. -2 < 1，因为负数小于正数。
3. -6 < -4，因为 -6 在数轴上位于 -4 左边。
4. -9。
5. 8。
6. 5，绝对值是距离。
7. 0。
8. 3 在右边，因为 3 > -2。
9. -4 ℃。
10. 不是。0 既不是正数，也不是负数。

提高题：
1. 5 或 -5，因为两者到原点的距离都是 5。
2. -3 < -1 < 0 < 2。
3. a 为负数，而 |a| 为正数；绝对值表示距离，且负数的绝对值为正数。
