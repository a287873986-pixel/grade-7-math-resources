# 七年级数学章节导航

本文件用于组织学习，不保证与每个修订年份的教材目录完全一致。请以学生手中实际使用的人教版教材目录为准，并在需要时更新章节名称与顺序。

## 上册学习主题

1. 有理数：正数与负数、数轴、相反数、绝对值
2. 有理数的运算：加减乘除、乘方、运算律、科学记数法
3. 代数式：用字母表示数、代数式及其值
4. 整式的加减：单项式、多项式、同类项、合并同类项
5. 一元一次方程：等式性质、解方程、实际问题
6. 几何图形初步：几何体、直线、射线、线段、角

## 下册学习主题

常见人教版七年级下册主题包括：

1. 相交线与平行线
2. 实数
3. 平面直角坐标系
4. 二元一次方程组
5. 不等式与不等式组
6. 数据的收集、整理与描述

> 重要：教材版本可能更新。开始正式学习前，请将学校实际使用教材的目录拍照核对，并根据目录修订本文件。章节导航不替代正式教材。
