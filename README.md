# 人教版七年级数学学习资源库

面向中国大陆初中七年级学生，尤其适合数学基础薄弱、需要从基础概念开始巩固的学习者。

## 目标

- 按人教版七年级数学上下册组织学习路径。
- 收录合法公开的官方课程入口和资源索引。
- 提供原创的知识讲解、例题、分层练习和答案解析。
- 强调“先理解概念，再模仿例题，最后独立练习”。

## 目录

- `resources/`：官方资源入口与授权核查记录
- `curriculum/`：教材章节导航（使用前请核对实际使用版本）
- `semester-1/`：上册原创基础讲义与练习
- `semester-2/`：下册学习导航与后续讲义目录
- `diagnostic-tests/`：基础摸底与复习练习
- `study-plan/`：学习计划与错题复盘方法
- `LICENSE`：本仓库原创内容的许可说明
- `COPYRIGHT.md`：第三方资源的版权与再分发规则

## 建议学习方法

每次学习 20–30 分钟：
1. 复习上次的 3–5 道错题。
2. 阅读一个知识点，尝试用自己的话复述。
3. 看懂一道例题后，遮住答案独立重做。
4. 完成基础题；正确率达到 80% 后再做提高题。
5. 记录错因：概念不清、符号错误、计算错误或审题错误。

## 版本说明

不同年份、地区及教材修订版本的章节名称和顺序可能存在差异。本仓库中的章节导航是学习组织框架，不代替学校实际使用教材。请对照纸质教材目录核验后再按章节学习。
