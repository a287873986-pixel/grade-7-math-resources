## 添加新资源前检查

1. 链接是否来自官方或可信发布者？
2. 版本是否与学校实际使用的教材一致？
3. 是否明确允许下载、复制、修改或再分发？
4. 若授权不明确，是否只保留链接而不复制文件？
5. 是否记录核验日期和资源适用范围？
